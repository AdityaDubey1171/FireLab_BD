How the Simulation Center Works

Six simple steps from choosing an attack to learning how to defend against it.

1. Select

Choose an attack simulation from the six available categories.

2. Enter Data

Provide harmless sample information for the simulator to analyze.

3. Analyze

Review the detection result, risk score and security explanation.

4. Firewall

Open the Firewall Lab to understand packet inspection and rules.

5. Review

Recorded simulation events can be reviewed through your admin area.

6. Defend

Each simulation explains practical defensive security controls.

Educational simulation: This project analyzes sample input only. It does not perform real network scanning, password guessing, database manipulation, DDoS traffic generation or unauthorized file access.
